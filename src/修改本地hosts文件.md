## mac 端
1. **打开终端**：
   - 你可以在`应用程序`文件夹中找到`实用工具`文件夹，然后打开`终端`，或者使用Spotlight搜索（按`Cmd + Space`键，然后输入“终端”）。
2. **使用文本编辑器打开hosts文件**：
   - 在终端中输入以下命令，然后按回车键：
     ```
     sudo nano /etc/hosts
     ```
   - 这将使用`nano`文本编辑器以管理员权限打开`hosts`文件。如果你更喜欢使用其他文本编辑器，如`vim`或`textmate`，你可以用相应的命令替换`nano`。
3. **输入管理员密码**：
   - 当系统提示你输入密码时，输入你的Mac管理员账户密码。输入时密码不会显示在屏幕上。
4. **编辑hosts文件**：
   - 使用键盘上的箭头键移动光标，并编辑文件内容。通常，你需要添加或修改指向特定IP地址的域名条目。例如：
     ```
     192.168.1.100 example.com
     ```
   - 每个条目都应该占据一行，并且IP地址和域名之间至少要有一个空格。
5. **保存并关闭文件**：
   - 在`nano`编辑器中，按`Ctrl + O`键来保存更改，然后按回车键确认文件名。
   - 接着按`Ctrl + X`键退出编辑器。
6. **刷新DNS缓存**（可选）：
   - 为了让修改生效，你可能需要刷新DNS缓存。在终端中输入以下命令：
     ```
     sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
     ```
完成以上步骤后，你所做的更改应该就会生效。如果需要验证是否成功，可以使用`ping`命令测试域名是否解析到新的IP地址。例如：
```
ping example.com
```
请记住，修改`hosts`文件会影响你的网络连接，错误的修改可能会导致某些网站无法访问。因此，在进行更改时请谨慎操作，并确保你知道自己在做什么。
